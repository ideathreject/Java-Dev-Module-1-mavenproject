# Maven Project – myname.jar

This repository contains a Maven project that generates an executable FatJar named `myname.jar`.

## 🧾 Task Description

This project is a part of the homework assignment. It must:

- Be built with **Maven**.
- Package the application as an **executable FatJar** named `myname.jar` when running:
  ```bash
  mvn package
- print the first and last name in JSON to the console when the command java -jar myname.jar launches. For example, {"name": "Vladyslav", "lastName": "Demchenko"}. For creating JSON string use any third-party library from Maven Central
- have the correct .gitignore file
